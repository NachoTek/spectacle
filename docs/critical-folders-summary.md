# Critical Folders Summary

- `src/`: Core application implementation (UI, capture logic, platform backends)
- `src/Gui/`: UI layer (Qt widgets + QML components)
- `src/Platforms/`: Platform capture/recording backends (KWin, XCB, Wayland)
- `dbus/`: DBus service/interface definitions
- `desktop/`: Desktop integration files
- `kconf_update/`: Configuration migration utilities
- `icons/`: Application icons
- `doc/`: User docs assets (screenshots)
- `tests/`: Test sources
- `po/`: Localization (.po, docbook translations)
